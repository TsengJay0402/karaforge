# 注音與拼音（ruby）

KaraForge 可以在每個中文字上方顯示小字的讀音：**注音**（預設，語言為 `zh-TW` 時）或**漢語拼音**（語言為 `zh-CN` 時）。
這份文件說明讀音怎麼來、怎麼修正，以及**自動讀音在破音字上有多準**。

## 怎麼使用

- 建立中文專案（`kf new`、`kf auto`、Web 的新增精靈、或由語音辨識產生草稿）時，每個中文字都會自動得到一個讀音，
  存在 `project.json` 的 `ruby` 欄位，`ruby_source` 為 `auto`。
- 要不要**顯示**由主題決定：主題的 `ruby.enabled`（Web 編輯器的主題面板有開關）。預設不顯示。
- 換成拼音、重新產生、或全部清掉：

  ```bash
  kf ruby my-song.kfproj                  # 重新產生（沿用目前的種類）
  kf ruby my-song.kfproj --kind pinyin    # 改用漢語拼音
  kf ruby my-song.kfproj --kind zhuyin    # 改用注音
  kf ruby my-song.kfproj --clear          # 移除所有自動讀音
  ```

  Web 編輯器的主題面板裡有同樣的按鈕。
- **手動指定的讀音永遠優先，而且不會被任何自動處理改掉。** 兩種指定方式：
  - 在歌詞裡寫 `字{讀音}`，例如 `一行{ㄏㄤˊ}白鷺上青天`；
  - 在編輯器選取那個字，在「讀音」欄位輸入。
- 手動讀音可以是任何文字（注音、拼音、台語羅馬字、假名都行），畫面上會照樣顯示。
  如果寫的是注音或拼音，對齊時也會用它當作那個字的發音。
- 日文、韓文等其他語言的專案不會自動產生讀音（漢字在日文裡不是唸國語）。

## 讀音怎麼決定

依序是：

1. **詞**：先用 OpenCC 的臺灣字表把整行轉成簡體（這一步同時分開了助詞「著」與「著名」的「著」），
   再用 [pypinyin](https://github.com/mozillazg/python-pinyin) 的詞庫斷詞；落在已知詞語裡的字採用詞語的讀音
   （銀**行** háng、音**樂** yuè、睡**覺** jiào）。
2. **虛詞規則**：讀音取決於文法而不是詞語的幾個高頻字——得、地、了、著、還——在沒有詞語涵蓋時依前後文判斷
   （跑**得**快 de、我**得**走了 děi、**得**到 dé；靜靜**地** de；忘不**了** liǎo；睡不**著** zháo；怎麼**還** huán）。
   「一」與「不」依後面的聲調變調（**一**個 yí、**一**天 yì、第**一** yī；**不**要 bú）。
3. **單字**：其餘的字取最常用的讀音；簡體合併而繁體有別的字以繁體為準（乾／幹、髮／發、隻／只…）。
4. **臺灣讀音**：語言是 `zh-TW` 時，套用一張與大陸審音不同的對照表，例如
   垃圾 ㄌㄜˋ ㄙㄜˋ、寂寞 ㄐㄧˊ ㄇㄛˋ、擁抱 ㄩㄥˇ ㄅㄠˋ、夕陽 ㄒㄧˋ ㄧㄤˊ、珍惜 ㄒㄧˊ、頭髮 ㄈㄚˇ、星期 ㄑㄧˊ、突然 ㄊㄨˊ、
   奇蹟 ㄐㄧ、認識 ㄕˋ、法國 ㄈㄚˋ、微笑 ㄨㄟˊ。
   這張表（`engine/karaforge/text/ruby.py` 的 `_TAIWAN_CHARS`、`_TAIWAN_WORDS`，共 42 項：34 個字、8 個詞）是依作者對教育部國語辭典讀音的認識整理的，
   **沒有逐項與辭典核對**；發現錯誤請回報。

輕聲的注音符號寫在前面（˙ㄇㄚ），一聲不標調。

這是**查表式**的方法，不是語言模型：它不懂句子的意思。沒有詞語也沒有規則涵蓋的破音字，只會得到最常見的讀音。

## 破音字準確率

### 測試集

`tests/fixtures/polyphones/zh-polyphones.tsv`：**171 個句子、68 個破音字**，每個字至少測兩種讀音。
句子是仿歌詞的短句，被測的字用【】標出，例如 `欠你的溫柔怎麼【還】	huan2`。

- 測試集是在撰寫讀音引擎**之前**寫好並提交到 git 的（commit `677c8b7`），之後沒有改過。
- 只收錄臺灣與大陸標準讀音一致的用例，所以它量的是「選對讀音」，不是地區差異。
- 預期讀音出自撰寫者（本專案的 AI 作者）對標準國語的認識，只用程式確認過「每個預期讀音都是該字確實存在的讀音」，
  **沒有由第二個人或外部辭典逐條驗證**。

### 結果

執行 `python scripts/eval_polyphones.py --failures` 可以重現（pypinyin 0.55.0、opencc-python-reimplemented 0.1.7，2026-11-21）：

| 方法 | 正確 | 準確率 |
|---|---:|---:|
| pypinyin，直接讀繁體原文 | 106 / 171 | 62.0% |
| pypinyin，先轉成簡體 | 151 / 171 | 88.3% |
| **KaraForge（上述四個步驟）** | **158 / 171** | **92.4%** |

讀這些數字時請留意：

- 多出來的 7 題全部來自虛詞規則（得 ×3、著 ×2、還、地）。這些規則與測試集是**同一位作者在同一天**寫的，
  而且是在測試集寫完之後——雖然規則本身是一般性的文法規則，但不能算是對測試集「盲測」。
  完全沒有這層疑慮的數字是第二列的 **88.3%**。
- 第一次量測就是 158 / 171。之後修了幾個在測試集以外的句子上發現的錯誤（輕聲的內部表示、「受得了」的「得」、
  「唯一」的「一」、詞語內的「一」「不」也統一變調），重新量測仍是 158 / 171。**沒有針對下面這 13 題做任何修改。**
- 測試集刻意只收破音字，而且每個字至少考兩種讀音，冷門讀音的比例比一般文字高得多；一般歌詞裡大部分的字不是破音字，
  破音字也多半是常見讀音，所以整首歌的讀音正確率應該比這個數字高——但那個數字**沒有量過**，不在這裡宣稱。
- 171 題的 95% 信賴區間大約是 ±4 個百分點。

### 讀錯的 13 題

| 句子 | 預期 | 得到 | 原因 |
|---|---|---|---|
| 兩【行】眼淚慢慢滑落 | hang2 | xing2 | 量詞「行」不在詞庫的詞語裡 |
| 頭髮留得很【長】 | chang2 | zhang3 | 詞庫把「很長」前後斷錯 |
| 一切【重】來 | chong2 | zhong4 | 「重來」不在詞庫 |
| 【彈】著吉他唱著歌 | tan2 | dan4 | 單用的動詞，取了較常見的名詞讀音 |
| 一張老【相】片 | xiang4 | xiang1 | 斷詞成「老相」 |
| 【教】我如何不想你 | jiao1 | jiao4 | 單用的動詞 |
| 【背】著行李去遠方 | bei1 | bei4 | 單用的動詞 |
| 風車不停地【轉】 | zhuan4 | zhuan3 | 單用的動詞 |
| 【切】開回憶 | qie1 | qie4 | 單用的動詞 |
| 太陽【落】下 | luo4 | la4 | 詞庫的「落下」是「遺落」的讀音 |
| 被你說【中】 | zhong4 | zhong1 | 單用的動詞補語 |
| 再【待】一會兒 | dai1 | dai4 | 單用的動詞 |
| 【盛】一碗湯 | cheng2 | sheng4 | 單用的動詞 |

共同點很清楚：**名詞與動詞讀音不同、而動詞單獨出現**的情況，查表法沒有辦法分辨。
這類字在歌詞裡遇到時，請用 `字{讀音}` 或編輯器手動指定。

### 用自己的清單量測

測試集的格式很簡單（一行一題：含【字】的句子、Tab、帶數字聲調的拼音，輕聲寫 5），可以拿自己的清單來量：

```bash
python scripts/eval_polyphones.py my-list.tsv --failures
```

## 已知限制

- 上面說的動詞／名詞破音字。
- 「一」的序數用法只認得常見的幾種（第一、十一、星期一、一月…）；「一流」「一年級」會被當成數量而變調。
- 歌手為了押韻或旋律改變讀音（把「的」唱成 dī、「了」唱成 liǎo）不會反映在自動讀音上。
- 臺語、客語、粵語歌詞：自動讀音一律是國語讀音，請關閉顯示或手動指定。
- 自動讀音不影響對齊（對齊用的是不帶聲調的發音，並且只採用手動讀音）。
- 沒有採用以語言模型消歧的做法（例如 g2pW）：準確率會更高，但要多下載數百 MB 的模型；列為後續工作。
